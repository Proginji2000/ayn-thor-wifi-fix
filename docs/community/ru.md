# AYN Thor — Руководство сообщества по исправлению Wi-Fi

[English](en.md) · [Français](fr.md) · [Español](es.md) · [Deutsch](de.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Русский](ru.md)

**Предварительная документация: публичного установщика пока нет.** Manual Edition RC1 и Permanent Edition V4.3 RC1 испытаны в частном порядке на одной консоли. Публичное распространение не одобрено.

## Совместимость
Испытаны только `Thor_V1.0.0.377_20260206_165408_user`, kalama, Android 13 (API 33), слот a. Другие прошивки, слоты, аппаратные варианты и OTA-обновления не проверены. При несовпадении версии или результатов проверки целостности остановитесь.

## Выбор редакции
- Manual Edition: частный многоразовый запускатель; активируйте после каждой полной загрузки. Активация перезапускает фреймворк Android и закрывает приложения. Полная перезагрузка восстанавливает исходные компоненты Wi-Fi. Полное удаление и усиленная установка RC2 не квалифицированы.
- Permanent Edition: частный модуль V4.3 RC1 для Magisk 31.1 на испытанном устройстве. Активируется до Zygote и дважды проверяет состояние системы. Пройдены три загрузки с исправлением, шесть проверок, повторная активация, защита при имитации неподтверждённой загрузки, отключение, удаление и повторная установка. Не используйте обе редакции одновременно.

## Что доступно сейчас
На полностью загруженной консоли с исходными компонентами Wi-Fi установите Python 3 и официальные [Android Platform-Tools](https://developer.android.com/tools/releases/platform-tools). Включите USB-отладку, подключите одно USB-устройство и разрешите подключение. Из корня репозитория выполните:
```bash
python3 tools/manual_preflight.py
python3 tools/manual_preflight.py --extract-stock thor-stock-private
```

В Windows при необходимости используйте `py -3` вместо `python3`. Укажите `--adb /path/to/adb`, если ADB находится по другому пути (adb.exe при использовании Windows ADB из WSL). Вторая команда создаёт новый локальный закрытый каталог. Инструмент только читает устройство, не получает root, не прошивает, не устанавливает и не перезагружает его. Не проверяйте исходное состояние при активном исправлении. Храните извлечённые файлы в частном порядке.

Уже собранный локально комплект можно проверить автономно:
```bash
python3 tools/manual_verify_bundle.py path-to-candidate
```

PASS подтверждает только точное совпадение хешей, но не разрешение установки. Публичный сборщик и полная процедура установки пока недоступны.

## Безопасность и восстановление
Перед будущей установкой сделайте резервную копию данных. Постоянная редакция требует независимо проверенной среды root и восстановления. Не используйте чужие изменённые загрузочные образы, не разблокируйте и не прошивайте устройство по этой предварительной документации. Не меняйте слоты и AVB. Остановитесь при неизвестной прошивке, несовпадении хешей, неподтверждённой загрузке или ошибке. Не удаляйте `pending` вручную. В испытанной частной установке отключите или удалите модуль в Magisk и нормально перезагрузитесь: восстановятся исходные компоненты Wi-Fi, но не загрузочный раздел и не состояние root. Для Manual перезагрузитесь без Enable. Восстановление после реального сбоя загрузки, устойчивость к отключению питания, физическое восстановление init_boot и длительная стабильность не проверены. Другие консоли не квалифицированы.

## Поддержка
Указывайте редакцию, прошивку, этап ошибки и обезличенные диагностические маркеры. Удалите серийные номера, идентификаторы загрузки, SSID, BSSID, адреса и личные данные. Не загружайте прошивки, JAR/ODEX/VDEX или загрузочные образы. После открытия поддержки используйте систему Issues репозитория. Независимый проект, не официальный выпуск AYN.
